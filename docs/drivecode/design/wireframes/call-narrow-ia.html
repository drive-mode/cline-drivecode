Why collapsible wins here

  • Spotlight stays on-screen — you still see the edit while steering.
  • Matches desktop split (Spotlight | feed) — one mental model, width changes.
  • Strip stays put; no sheet fighting safe-area / Leave.
  • Reuses existing feed-collapse chrome already in Chat.tsx.

When a sheet would still help

  • Deep settings / pack picker that needs full width.
  • One-shot confirmations (end call, approval) — keep those as dialogs.
  • Not the default for roster/feed during an active watch loop.
