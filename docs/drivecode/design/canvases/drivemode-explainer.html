Drive

Drive mode · pair-program on a call inside Cline

Cline runs agents; Drive is a Cline mode that makes running them feel like being on a call. Discord-style rooms, a Spotlight of structured work, interruptible turns, privacy-strict by default.

What it adds

Five surfaces, one mode

Drive sits on native Cline. It does not replace the agent loop or fork ConfiguredAgent YAML — it makes the same runtime feel like joining a call.

📞

Call room

Join, roster, stay in the call. Chat Join is a shortcut into the active room — not a second product home.

💡

Spotlight

Typed stage cards for edits, commands, tests, plans, and decisions — events first, not pixels.

✋

Address + interrupt

Address one, many, or everyone. Raise a hand to pause after the current tool; steer mid-turn without fighting the agent.

🎛

Mode overlay

Drive on the same control family as Plan / Act. Postures Plan, Agent, Ask, and Debug while Drive stays on.

📋

Status Hub

Durable cross-agent status — Board, Changelog, Sessions — on status.db with a seq cursor.

Contract

Three verbs

The harness proposes, the host commits, apps project. That split is the architecture — not a slogan.

1 · harness

Proposes

@cline/drive owns mode, narration, and interrupt policy. Pure, testable — no UI, no transport, no persistence of its own.

→
2 · host

Commits

@cline/core applies hooks and runs turns. Hub is the only writer of room state. Clients publish facts and receive broadcasts.

→
3 · apps

Project

Chat, Drive tab, Spotlight, Status Hub, and CLI are thin renderers of the same event stream — never writable client copies of room state.

Do not conflate

Naming firewall

Drive words and native Cline words look adjacent. Mixing them forks the model.

RosterPackseating preset
≠
Teamruntime execution group
Curated pack expands into participants. Never rename Cline Team to RosterPack.
AgentProfileappearance overlay
≠
ConfiguredAgentbehavior definition
Display name + ink channels overlay .cline/agents/*.yaml. Prompts and tools stay on the host.
Spotlightproduct UI label
≠
stagewire protocol field
Surfaces say Spotlight; hub still says stage / StageState / call_set_stage.
Roomcollaboration unit
≠
Sessionagent turn container
Room holds participants, stage, addressSet. Session remains the turn lifecycle container underneath.
Overlay, not fork

What we deliberately reuse

Drivecode is an overlay on native Cline — keep these, do not invent a parallel stack.

Hub on :25463
Single writer. Nothing defaults to :7891. No second daemon.
ConfiguredAgent / .cline/agents/*.yaml
Prompts, tools, skills, provider, and model stay here. Drive owns appearance in a call — nothing else.
Cline Team
Runtime execution group. RosterPack is seating only — never rename Team.
Hook engine
Drive policies decide; core applies. No chrome DOM hacks, no monkey-patches.
Pending-prompt / turn queue
Steer queue builds on existing primitives rather than a side channel.
Bundled ai-elements
Stage cards render with existing UI building blocks — assembly work, not component invention.
