# SDK integration backlog

Items filed by post-task review and test-coverage agents. Product decisions live in `@cline/core` [`product-host-policy.ts`](https://github.com/cline/cline/blob/main/sdk/packages/core/src/session/product-host-policy.ts) so hosts can flip defaults without rewiring call sites.

## Product policy defaults

| Decision | Default | Flip |
|----------|---------|------|
| Plugin injection | Pass `pluginPaths` + workspace (D3) | `PRODUCT_HOST_WORKSPACE_ONLY_PLUGIN_INJECTION` |
| Hub host `AgentHooks` | Off (Desktop parity; file hooks on daemon) | `CLINE_HUB_HOST_AGENT_HOOKS=1` or `PRODUCT_HUB_HOST_AGENT_HOOKS_DEFAULT` |
| Hub Chat `cline_type` | `hub-chat` (daemon stays `hub`) | `PRODUCT_HUB_CHAT_CLINE_TYPE` |
| Telemetry opt-out | Recreate + `restartHub` | `PRODUCT_HUB_RECREATE_TELEMETRY_ON_OPT_OUT` |
| PreCompact | On; cancel aborts compaction | `PRODUCT_VSCODE_PRECOMPACT_HOOKS` / `PRODUCT_PRECOMPACT_CANCEL_ABORTS` |
| Notification hooks | On (approval site) | `PRODUCT_VSCODE_NOTIFICATION_HOOKS` |
| TaskError / SessionShutdown | Notification stand-ins (`task_error` / `session_shutdown`) until HookFactory proto kinds exist | `PRODUCT_VSCODE_TASK_ERROR_AS_NOTIFICATION` / `PRODUCT_VSCODE_SESSION_SHUTDOWN_AS_NOTIFICATION` |
| Legacy VS Code OTEL | Shared env fallback under BUILD_CONSTANTS | `PRODUCT_VSCODE_LEGACY_OTEL_USE_SHARED_ENV` |
| USD session budget | Opt-in `CLINE_MAX_SESSION_COST` (+ VS Code `maxSessionCostUsd` setting) | env / setting |

## Hooks coverage matrix

| Surface | File hooks (`.clinerules/hooks`) | Host `AgentHooks` |
|---------|----------------------------------|-------------------|
| Hub daemon / Hub-backed sessions | Yes — Core bootstrap | Off by default (`CLINE_HUB_HOST_AGENT_HOOKS` to request) |
| Hub Chat process | Same as daemon when session runs on hub | Same policy gate |
| CLI | Yes via Core bootstrap | Yes — `createRuntimeHooks` |
| Desktop sidecar | Yes via Core bootstrap when applicable | No |
| VS Code | HookFactory (+ host PreCompact/Notification) | Yes — `hooks-adapter` |
